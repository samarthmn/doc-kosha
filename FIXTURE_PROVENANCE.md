## Synthetic public application assets

The two maintained application assets are generated by
`scripts/generate-public-fixtures.mjs` using the checked-in `pdf-lib` and
`sharp` dependencies. The generator has no network input and writes stable
bytes (including fixed PDF dates). The PDF is one 612x792-point page containing
project-written preview prose and vector layout only; it has no embedded fonts
or personal metadata. The PNG is a true 1024x1024 RGBA PNG of a generic
abstract document-pattern placeholder. An unused `public/grid.svg` placeholder
was removed rather than replaced. These are synthetic fixtures;
the provenance record makes no claim of human authorship or legal signoff.
