This section takes you from nothing to a working shared link. Four short pages, in order.

## The path

1. **[What DocKosha is](/docs/getting-started/what-is-dockosha)** — the product in one page: documents, data rooms, and gates that are checked on the server.
2. **[Quickstart](/docs/getting-started/quickstart)** — get a workspace you can sign in to on DocKosha Cloud.
3. **[Your first document](/docs/getting-started/first-document)** — upload a file and confirm it previews.
4. **[Your first shared link](/docs/getting-started/first-link)** — create a link, put a password on it, and open it the way an outside viewer would.

After that, the [Guides](/docs/guides) section covers one task per page: link gates, data rooms, watermarking, analytics, and administration.

## What you need before you start

- An account on [DocKosha Cloud](https://dockosha.com). External self-hosting is not currently available.
- A workspace with an active plan. Documents, links, and data rooms are only readable and servable while the workspace has an active plan record — the Free plan counts. The Quickstart covers this.
- A PDF to upload. Other formats work on paid plans; the Free plan accepts PDF only.

## What "gated" means here

Every access rule you set on a link — password, email verification, expiry, allow and block rules, NDA — is checked by the server before any document bytes are released. The viewer's browser never holds the decision.

Two controls are deliberately weaker than that, and the docs say so on every page where they appear:

- **Screenshot protection is a best-effort deterrent.** It blurs content and reacts to common screenshot hotkeys. No browser can block an operating-system screen capture, a screen recorder, or a phone camera pointed at the monitor.
- **Document conversion fails closed.** If a non-PDF file cannot be converted inside its validated envelope, the conversion is marked failed and the original file is served instead. A degraded or partial rendering is never substituted.
