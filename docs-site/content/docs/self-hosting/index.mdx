The DocKosha source is public under AGPL-3.0-or-later for reading and contribution.
External self-hosting is not currently available because the mandatory DocYantra
dependency is private. Gotenberg is a future-only provider path and is not an
available fallback or supported self-hosting option today. The synced pages
below are technical reference material for authorized maintainers, not an
external installation guide.
