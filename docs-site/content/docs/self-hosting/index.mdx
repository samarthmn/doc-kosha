DocKosha and its DocYantra processing engine are both open source under
AGPL-3.0-or-later. Use [DocKosha Cloud](https://www.dockosha.com) for managed
hosting, or operate the application on your own infrastructure. Self-hosting is
not officially supported; community help is best effort.

## Start with the setup guide

The [complete self-hosting walkthrough](/docs/self-hosting/self-hosting) covers
installation, local Supabase and MinIO, email sign-in, a first shared document,
production deployment, backups, and upgrades. It is synchronized from the
repository's canonical guide so fixes reach both readers.

You need Node.js 24.x, pnpm 11.25.0, Supabase, S3-compatible storage, and SMTP.
Local services use Docker. DocYantra `0.0.28` runs inside the application through
its packages; there is no separate conversion service. Installing those public
packages from GitHub Packages requires a classic GitHub token with
`read:packages` access.

## Choose what you operate

Self-hosters manage database migrations, storage permissions, auth, email,
secrets, HTTPS, backups, security updates, and monitoring. The repository's
Compose file starts local object storage, not a complete production stack.
[Compare Cloud and self-hosting](https://www.dockosha.com/hosted-vs-self-hosted)
if you are deciding which responsibility fits your team.
