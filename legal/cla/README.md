# Contributor License Agreements

The individual and corporate CLA template texts in this directory have been
approved by the project owner. The acceptance and enforcement workflow is not
yet active. Template approval does not constitute a contributor's acceptance.
No independent counsel sign-off is represented by this status.

The counterparty for these drafts is Sublime Innovation Technologies Limited;
DocKosha is the project/product name used in the individual and corporate
forms.

The intended grant lets the project distribute contributions under the
AGPL-3.0-or-later license and separately grant commercial licenses under a signed
agreement. It does not itself create an Enterprise agreement.

The drafts apply to contributions to DocKosha. They do not offer contributors
access to the private DocYantra repository, packages, SDKs, or APIs.

## Activation requirements

Before outside code is merged, the project must publish the approved agreement
version and acceptance instructions and verify the required
contributor check. A contributor's employer must provide the necessary
authorization where it owns rights in the contribution. An approved corporate
agreement also needs an authorized signatory and a maintained list of covered
contributors; an individual GitHub signature alone does not establish that.

Keep agreement records, corporate schedules, and contact details in a private
signature store with restricted access. A signature statement posted on a
public pull request remains public even when the stored record is private.
Publish the collection and retention information before collecting signatures.

The acceptance check must be tested with an unsigned contributor and must
block merging until a valid agreement covers the contribution. Retain the
exact signed agreement version and test that the record is written only to
the private store. The presence of these templates or passing ordinary CI does
not establish that any agreement has been signed or that enforcement is active.

Until activation, follow the contribution restrictions in
[CONTRIBUTING.md](../../CONTRIBUTING.md).
