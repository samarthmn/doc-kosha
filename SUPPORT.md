# Support

Source review and contribution support is available at
[support@dockosha.com](mailto:support@dockosha.com). Include the DocKosha
version, provider configuration category, and steps to reproduce. Sanitise any
diagnostic output, and never send credentials or customer content.

Self-hosting is available at your own risk and is not officially supported;
self-hosting questions get community help only. Hosted DocKosha Cloud
customers should use the support channel specified in
their service agreement. Cloud support can investigate managed infrastructure
and account-specific issues; community support cannot access a hosted
workspace.

For security vulnerabilities, use the private process in
[SECURITY.md](./SECURITY.md), not a public issue.
