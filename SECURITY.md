# Security

Please report suspected vulnerabilities privately to
[support@dockosha.com](mailto:support@dockosha.com). Do not open a public issue
for an unpatched vulnerability.

Initial reports should contain no secrets, credentials, customer data, or
private documents. Describe the affected component, the conditions needed to
reproduce the issue, its impact, and a safe way to contact you. We will use
the information to investigate and coordinate a response; no response time
or remediation deadline is promised here.

For ordinary bugs, questions, or self-hosting help, use the channels described
in [SUPPORT.md](./SUPPORT.md).
