## Evaluation checklist (what actually matters)

| Criteria          | Why it matters                                                                            |
| ----------------- | ----------------------------------------------------------------------------------------- |
| Clear free limits | You need transparent storage, bandwidth, file-type, and user caps before migration effort |
| Access gates      | Password/OTP/allowlist/NDA controls decide who can open sensitive material                |
| Watermarking      | Deters casual forwarding and improves handling discipline                                 |
| Download controls | Prevents unnecessary file export when view-only is safer                                  |
| Viewer analytics  | Shows whether key stakeholders actually reviewed documents                                |
| Privacy model     | Good analytics should not require aggressive personal data collection                     |
| Upgrade path      | Free should scale cleanly when your room grows                                            |

## Honest claim boundaries

No free VDR is perfect for every deal size or compliance context.

DocKosha Free is optimized for lightweight, controlled workflows. It is not an unlimited enterprise plan and should not be represented that way. If your process quickly needs larger rooms, teammates, or custom branding/domain controls, paid is the right path.

## Free VDR vs free cloud storage

Use free cloud storage for internal file sync. Use a free VDR when reviewers are external and governance matters.

A VDR-style workflow is usually better when you need:

- controlled document access
- explicit download decisions
- watermarking
- engagement signals for follow-up

## FAQs

**What is a free VDR?**  
A free VDR is a no-cost plan for controlled document sharing, typically with explicit limits.

**Is free virtual data room software always safe?**  
No. Safety depends on access controls, download policy, watermarking, and implementation discipline.

**Should startups use a free data room?**  
Usually yes for early-stage diligence and evaluation, then upgrade as collaboration and volume increase.

**Is DocKosha Free unlimited?**  
No. It is intentionally limited: 250 MB storage, 2 GB/month public bandwidth, PDF-only uploads, one owner, and required DocKosha branding.
